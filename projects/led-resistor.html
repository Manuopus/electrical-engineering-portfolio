Measuring LED current with an Arduino Nano

Predict the current through an LED at three different series resistances, then measure it with an Arduino Nano used as a voltmeter, and check whether Ohm's law holds.

Objective

A series resistor limits the current through an LED. This project tests that relationship with real measurements: if the resistance is halved, does the current double?

I don't have a multimeter, so the Arduino Nano does the measuring. Its analog inputs read voltages, and Ohm's law turns the voltage across a known resistor into a current. All parts come from the Franzis Maker Kit for Arduino.

Theory

Ohm's law

For a resistor, voltage U (volts, V), resistance R (ohms, Ω) and current I (amperes, A) are linked by:

U = R · I   ⇔   I = U / R

Kirchhoff's voltage law

In a series loop, the supply voltage is shared between the parts. The LED takes the voltage ULED and the resistor takes the rest:

UB = ULED + UR   ⇒   UR = UB − ULED

The same current flows through every part of a series circuit, so measuring the current in the resistor also gives the current in the LED.

Series and parallel resistors

Two 10 kΩ resistors give two more resistance values:

Series: R = R1 + R2

Parallel: 1/R = 1/R1 + 1/R2

An LED with a built-in resistor

The kit's LEDs contain their own series resistor, whose value is not given. What the Arduino measures across the LED is therefore the LED's forward voltage plus the small voltage across that hidden resistor.

The Arduino as a voltmeter

analogRead() returns a number N from 0 to 1023, where 1023 means "equal to the supply voltage UB":

U = N / 1023 · UB

UB is never exactly 5.00 V, so the program first measures the Nano's 3.3 V pin, a known voltage, and works out the real supply voltage from it:

UB = 3.3 V · 1023 / N3V3

Design and calculation

Given values

  • Supply voltage: UB ≈ 5.0 V (USB)
  • Voltage across the LED: ULED ≈ 2.0 V (assumed for a red LED, to be measured)
  • Known resistor: R = 10 kΩ = 10 000 Ω

Step 1: voltage across the resistor

UR = UB − ULED

UR = 5.0 V − 2.0 V

UR = 3.0 V

Step 2: predicted current

I = UR / R

I = 3.0 V / 10 000 Ω

I = 0.0003 A = 0.30 mA

Far below the 20 mA an LED usually allows, so the LED glows dimly and safely.

Step 3: power in the resistor

P = UR · I

P = 3.0 V · 0.0003 A

P = 0.0009 W = 0.9 mW

Tiny: the resistor stays cold.

Step 4: the other two setups

Setup B, two 10 kΩ in parallel:

1/R = 1/10 000 Ω + 1/10 000 Ω = 2/10 000 Ω

R = 5 000 Ω = 5 kΩ

Setup C, two 10 kΩ in series:

R = 10 000 Ω + 10 000 Ω

R = 20 000 Ω = 20 kΩ

Hypothesis: halving the resistance doubles the current, and doubling it halves the current.

Measurement program

The Nano reads A0 (the point between the resistor and the LED) and A1 (connected to the 3.3 V pin). Each value is the average of 20 readings to reduce noise. The results are printed once a second, separated by tabs so they can be pasted into a spreadsheet. 

// Project 02 – LED current measurement with an Arduino Nano
// Wiring: 5V -> R_KNOWN -> node X (A0) -> LED -> GND
//         A1 -> 3V3 pin (known reference voltage)

const float R_KNOWN = 10000.0;  // ohms: 10000 (A), 5000 (B), 20000 (C)
const float V_3V3   = 3.3;      // voltage of the 3V3 pin
const int   SAMPLES = 20;       // readings averaged per measurement

// Reads a pin 20 times and returns the average, to reduce noise
float averageRead(int pin) {
  long sum = 0;
  for (int i = 0; i < SAMPLES; i++) {
    sum += analogRead(pin);
    delay(2);
  }
  return sum / (float)SAMPLES;
}

void setup() {
  Serial.begin(9600);
  Serial.println("Vcc[V]\tU_LED[V]\tU_R[V]\tI[mA]");
}

void loop() {
  float raw3v3 = averageRead(A1);
  float rawLed = averageRead(A0);

  float vcc  = V_3V3 * 1023.0 / raw3v3;  // real supply voltage
  float uLed = rawLed * vcc / 1023.0;    // voltage across the LED
  float uR   = vcc - uLed;               // voltage across the resistor
  float iMa  = uR / R_KNOWN * 1000.0;    // current in mA (Ohm's law)

  Serial.print(vcc, 3);  Serial.print("\t");
  Serial.print(uLed, 3); Serial.print("\t");
  Serial.print(uR, 3);   Serial.print("\t");
  Serial.println(iMa, 3);

  delay(1000);
}
